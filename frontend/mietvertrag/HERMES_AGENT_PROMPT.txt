STEP 3 — BUILD AND START DOCKER CONTAINER
──────────────────────────────────────────
  cd /opt/apps/mietvertrag
  sudo docker compose up -d --build

This will:
  1. Pull node:20-alpine
  2. Install npm dependencies inside container
  3. Run: npm run build (Vite compiles React → /dist)
  4. Pull nginx:alpine
  5. Copy /dist into Nginx container
  6. Start container on port 3010

Build takes ~60-90 seconds on first run.

Verify the container is running:
  sudo docker ps
  # Should show: mietvertrag   Up X seconds   0.0.0.0:3010->3010/tcp

Test it locally:
  curl -s http://localhost:3010 | head -5
  # Should return HTML starting with <!doctype html>

STEP 4 — TEMPORARY HTTP NGINX CONFIG (for Certbot)
────────────────────────────────────────────────────
Before SSL, set up a plain HTTP proxy so Certbot can verify the domain.

  sudo nano /etc/nginx/sites-available/mietvertrag.mycontentpilot.de

Paste this exact content:

──────────────────────────────────────────
server {
    listen 80;
    server_name mietvertrag.mycontentpilot.de;

    location / {
        proxy_pass http://localhost:3010;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
──────────────────────────────────────────

Enable it and reload:
  sudo ln -s /etc/nginx/sites-available/mietvertrag.mycontentpilot.de \
             /etc/nginx/sites-enabled/
  sudo nginx -t
  sudo nginx -s reload

Verify in browser: http://mietvertrag.mycontentpilot.de
(Should load the Mietvertrag Generator app over HTTP)

TROUBLESHOOTING
────────────────
Container won't start:
  sudo docker logs mietvertrag

Nginx 502 Bad Gateway:
  → Container not running. Run: sudo docker compose up -d

Port 3010 conflict:
  → Edit docker-compose.yml, change "3010:3010" to "3011:3010"
  → Update proxy_pass in Nginx to http://localhost:3011

Certbot fails (DNS not resolving):
  → Wait longer for DNS propagation
  → Check: dig mietvertrag.mycontentpilot.de +short

Permission denied on /opt/apps:
  → sudo chown -R $USER:$USER /opt/apps
